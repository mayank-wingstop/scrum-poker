## Objective and Scope

Validate that the F-000 bootstrap phase satisfies every success criterion in `specs/1_features/F-000.MD`:

- `npm install` completes without errors
- `npm run build` compiles all workspaces successfully
- `npm test` runs and all baseline tests pass
- `npm run dev` starts both client and server for local inspection
- Coverage thresholds defined in `specs/TESTING.MD` are met
- The health endpoint (`GET /health`) responds correctly
- The client renders a visible placeholder page in the browser

F-000 has **no named design decisions** — Design (Stage 2) and Architecture (Stage 3) were intentionally skipped for the bootstrap phase. The Design-Decision Traceability table will reflect this.

## Test Scenarios

### S-01 — npm install exits 0
**Pass:** Exit code 0, no unresolved peer dependency errors.
**Fail:** Non-zero exit code or unresolvable errors.

### S-02 — Full build compiles all workspaces
**Pass:** `npm run build` exits 0; all three workspaces emit compiled output.
**Fail:** TypeScript or Vite compilation errors.

### S-03 — All unit tests pass
**Pass:** `npm test` exits 0; all 6 tests green (3 client, 3 server).
**Fail:** Any test failure.

### S-04 — Coverage thresholds met
**Pass:** Each workspace meets lines ≥ 80%, branches ≥ 75%, functions ≥ 80%, statements ≥ 80%.
**Fail:** Any threshold missed.

### S-05 — Health endpoint returns correct response
**Pass:** `GET /health` → HTTP 200, body `{ "status": "ok" }`.
**Fail:** Wrong status code or body.

### S-06 — WebSocket server accepts connection
**Pass:** Client can open a WS connection without error.
**Fail:** Connection refused or immediate error.

### S-07 — Malformed WS message returns ERROR event
**Pass:** Sending non-JSON to the WS server results in `{ type: "ERROR", payload: { message: "Invalid message format" } }`.
**Fail:** Server crashes, no response, or wrong response shape.

### S-08 — Dev server starts; client renders at :5173
**Pass:** `npm run dev` outputs "Server listening on port 3001"; page at `http://localhost:5173` shows "Scrum Poker" heading.
**Fail:** Either server fails to start or heading is absent.

### S-09 — Lint exits 0
**Pass:** `npm run lint` exits 0 with no errors.
**Fail:** Any lint error.

### S-10 — Typecheck exits 0
**Pass:** `npm run typecheck` exits 0 across all workspaces.
**Fail:** Any TypeScript type error.

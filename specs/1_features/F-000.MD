# F-000 — Project Bootstrap

> **IMPORTANT:** This file is a generic bootstrap template and must NOT be modified. Project-specific initialization decisions are captured in the stage output files (2_design, 3_architecture, 4_implementation-plan, etc.).

---

## Context

Every new project using the Trusted AI Delivery Framework (TADF) must complete a mandatory bootstrap phase before any product features are delivered. The bootstrap phase initializes the repository with the correct structure, tooling, scaffolding, CI pipeline, and baseline test suite.

This feature (`F-000`) represents that bootstrap phase.

---

## Goals

1. Establish the project's technology stack and monorepo structure.
2. Scaffold the initial application skeleton (frontend and backend) with no business logic.
3. Configure the CI pipeline with build, lint, and test steps.
4. Define and validate baseline test commands that the testing-specialist agent will use throughout the project lifecycle.
5. Ensure the full test suite command (`npm test`) runs successfully and produces a measurable coverage baseline.
6. Verify the application can be started locally for manual inspection.

---

## Non-Goals

- Delivering any product feature or user-visible functionality.
- Setting up production infrastructure or deployment pipelines.
- Implementing authentication, databases, or external integrations.

---

## Constraints

- Bootstrap must use only the technologies and conventions defined in `specs/SYSTEM.MD` and `specs/ARCHITECTURE.MD`.
- The scaffolded application must compile without errors.
- At least one passing test must exist in each workspace after bootstrap.
- CI must pass on the bootstrap commit before F-001 work begins.

---

## Open Questions

_To be resolved during the Design and Architecture stages of F-000._

- What is the minimum viable scaffolding for the chosen stack?
- What linting and formatting rules should be enforced?
- What is the baseline test coverage threshold?
- Should Playwright E2E tests be set up in F-000 or deferred to F-001?

---

## Success Criteria

- `npm install` completes without errors.
- `npm run build` compiles all workspaces successfully.
- `npm test` runs and all baseline tests pass.
- `npm run dev` starts both client and server for local inspection.
- CI pipeline (GitHub Actions) runs and passes on the `main` branch.
- `specs/INDEX.MD` shows F-000 as ✅ across all 7 stages.

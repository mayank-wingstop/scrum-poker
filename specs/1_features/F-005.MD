# F-005 — Results Display

## Context

After the facilitator reveals cards (F-004), participants need to see a clear summary of the results — not just the raw votes but derived statistics that help the team reach consensus: the average, the range, and which values the most people chose. This feature delivers the post-reveal results panel that replaces (or overlays) the card deck area after `CARDS_REVEALED` is received.

The results panel stays visible until the facilitator starts a new round (`ROUND_RESET`), at which point it disappears and the deck returns.

---

## Goals

1. After `CARDS_REVEALED`, render a **results panel** showing:
   - Each participant's name alongside their flipped card value.
   - The **average** (mean of numeric votes only; `?` and `☕` excluded from average calculation).
   - The **vote distribution** — a simple bar or count showing how many people chose each value.
   - A **consensus indicator**: highlighted "Consensus!" banner when ≥ 75% of numeric votes share the same value.
2. Cards in the participant list flip face-up with a CSS animation (flip transition).
3. Special cards (`?` and `☕`) are displayed with their symbol; they are counted in the distribution but excluded from numeric averages.
4. The results panel disappears when `ROUND_RESET` is received and the deck returns.
5. The results are visible to all participants equally (no facilitator-only information).

---

## Non-Goals

- Saving or exporting results to any external system.
- Detailed per-story history within the session (deferred to a future feature).
- AI-powered estimation suggestions.
- Weighted voting or custom consensus thresholds (F-008).

---

## User Stories

**US-005-A — All participants see flipped votes**
> As a participant, after cards are revealed I want to see everyone's card flipped face-up at the same time so I can compare estimates instantly.

**US-005-B — Team sees the average**
> As a participant, I want to see the numeric average of all votes (excluding `?` and `☕`) so I have a quick anchor for the discussion.

**US-005-C — Team sees vote distribution**
> As a participant, I want to see a breakdown of how many people voted for each value so I can quickly spot outliers and clusters.

**US-005-D — Team sees consensus indicator**
> As a participant, when the team converges on a single value I want to see a clear "Consensus!" signal so the facilitator knows we agree without further discussion.

**US-005-E — Results disappear on reset**
> As a participant, when the facilitator starts a new round I want the results panel to disappear and the deck to reappear so I know we're voting again.

---

## Constraints

- Average is calculated client-side from the `CARDS_REVEALED` payload; only numeric `CardValue` items are included.
- Consensus threshold: ≥ 75% of numeric votes on the same value triggers the consensus banner. If fewer than 2 numeric votes exist, the consensus indicator is not shown.
- The card-flip animation must be a CSS transform (`rotateY`) — not a JavaScript animation library — to keep the bundle light.
- `?` and `☕` votes are shown in the distribution as their own categories with counts.
- The results panel must be accessible: vote values must not be communicated only through color; each card must have a text label.
- The panel must be responsive — results shown as a wrapping grid on mobile.
- No server changes are required for this feature; all results logic is client-side derivation from the `CARDS_REVEALED` payload already received in F-004.

---

## Derived Statistics Logic

```
numericVotes = votes.filter(v => typeof v === 'number')
average      = numericVotes.length > 0
                 ? round(sum(numericVotes) / numericVotes.length, 1)
                 : null

distribution = group votes by value, count each group

consensus    = numericVotes.length >= 2
                 && max(distribution[numeric]) / numericVotes.length >= 0.75
```

## Success Criteria

- After `CARDS_REVEALED`, every participant's name and card value are shown in the results panel.
- The card flip from face-down to face-up plays a CSS animation.
- The numeric average is displayed (rounded to one decimal place), excluding `?` and `☕`.
- A vote distribution row appears for each distinct value that was voted.
- When ≥ 75% of numeric votes share the same value, a "Consensus!" banner is shown.
- When `ROUND_RESET` is received, the results panel disappears and the card deck reappears.
- Accessibility: each card value is also present as text, not color-only.
- Layout is usable at 375 px width.
- All existing tests pass; new tests cover the statistics derivation functions and the results panel rendering.
- Coverage thresholds from `specs/TESTING.MD` maintained.
